# Remez RMD-314 Local

Небольшое Windows-приложение для локального управления осушителем **Remez RMD-314** через протокол Tuya, без постоянного обращения к облаку.

## Возможности

- включение и выключение;
- текущая и целевая влажность;
- температура;
- скорость вентилятора;
- таймер;
- ионизатор;
- блокировка от детей;
- ресурс фильтра и состояние ошибок;
- автоматическое обновление показаний;
- диагностика исходных DP-параметров.

## Требования

- Windows 10 или 11;
- Python 3.10 или новее, доступный командой `python`;
- осушитель, уже добавленный в Smart Life;
- компьютер и осушитель в одной локальной сети.

## Получение данных подключения

Для локального протокола нужны IP-адрес, Device ID и Local Key. Получить Device ID и Local Key можно через [Tuya IoT Platform](https://iot.tuya.com/) и TinyTuya Wizard.

После создания и авторизации облачного проекта Tuya выполните в папке программы:

```bat
.venv\Scripts\python.exe -m tinytuya wizard
```

Если виртуальная среда ещё не создана, сначала один раз запустите `run.bat`.

Wizard создаст `devices.json`. Приложение автоматически загрузит из него Device ID и Local Key осушителя. IP-адрес можно посмотреть в роутере или найти командой:

```bat
.venv\Scripts\python.exe -m tinytuya scan
```

Не сбрасывайте и не перепривязывайте осушитель после получения Local Key: ключ может измениться.

## Запуск

Дважды щёлкните `run.bat`. При первом запуске будет создана виртуальная среда и установлена зависимость TinyTuya.

Укажите IP-адрес, выберите версию протокола Tuya и нажмите **«Подключиться»**. Для большинства устройств начать можно с версии `3.3`.

IP-адрес, Device ID, версия протокола и настройка автообновления сохраняются в `settings.json`. Local Key отдельно в этот файл не записывается.

## Безопасность

Файлы `devices.json`, `tinytuya.json`, `tuya-raw.json`, `snapshot.json` и `settings.json` содержат локальные или персональные данные и исключены из Git. Не публикуйте их и не отправляйте Local Key или Access Secret другим людям.

После проверки локального управления можно запретить осушителю доступ в интернет на роутере. Приложению нужен только доступ к локальной сети.
